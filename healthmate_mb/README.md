# Healthmate (Arogya Vani) - Developer Notes

This repository contains an in-progress Flutter app that delivers verified health information in multiple Indian languages with text-to-speech, offline caching, and push notification support.

What I implemented so far
- App skeleton with Splash, Language selection, and Home screen.
- News fetching service scaffold (NewsAPI) and caching using Hive (stores 20 latest articles).
- Text-to-speech wired to each news card using `flutter_tts`.
- Firebase initialization placeholder and `PushService` wiring for foreground notifications (requires proper `firebase_options.dart`).

Quick setup
1. Ensure Flutter SDK is installed and in PATH.
2. From the project root run:

```powershell
cd c:\Users\kp593\OneDrive\Desktop\Healthmate_mb\healthmate_mb
flutter pub get
```

3. Replace the placeholder NewsAPI key in `lib/services/news_service.dart`:
- Open the file and set `_apiKey = '<YOUR_NEWSAPI_KEY>'`.

4. Firebase setup
- The project contains an Android `google-services` JSON file. Rename or move it to `android/app/google-services.json` if needed.
- Replace `lib/firebase_options.dart` with the file generated by `flutterfire configure` or the platform options from Firebase.
- Then rebuild the app.

5. Running on device/emulator:

```powershell
flutter run
```

Quick push testing (without FCM)
- Open the app and go to Settings -> Simulate Alert to see a local notification immediately.

Using FCM (when configured)
- Use `tools/sample_send_fcm.js` with your server key and token to send a test message:

```powershell
node tools/sample_send_fcm.js <SERVER_KEY> <DEVICE_TOKEN_OR_/topics/healthmate_all>
```

Push notifications (sending test messages)
- For testing, you can use the Firebase Console (Cloud Messaging) to send messages to your device.
- Or use the sample Node.js script below. You need the server key from Firebase Project Settings > Cloud Messaging > Server key.

sample_send_fcm.js
```js
// Node.js sample to send FCM message to a topic or token
const fetch = require('node-fetch');
const serverKey = '<YOUR_SERVER_KEY>'; // replace
const token = '<DEVICE_FCM_TOKEN>'; // or send to /topics/all

const payload = {
  to: token,
  notification: {
    title: 'Healthmate Alert',
    body: 'This is a test critical health advisory.'
  },
  data: { urgent: 'true' }
};

fetch('https://fcm.googleapis.com/fcm/send', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'key=' + serverKey
  },
  body: JSON.stringify(payload)
}).then(res => res.json()).then(console.log).catch(console.error);
```
